# Dormate

An iOS app for matching college students with compatible roommates. Built natively in Swift.

## Features

- Onboarding flow that captures lifestyle preferences (sleep schedule, cleanliness, guests, study habits)
- - Editable user profiles
  - - Account creation and authentication
    - - Match browsing to find compatible roommates
